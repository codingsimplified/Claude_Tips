
Prompt 1 – Find Your Digital Footprint

Search the public internet for everything you can find about me.

Look for:
- Data broker websites
- People search websites
- Public directories
- Social media profiles
- Cached pages
- Public records
- Old accounts
- Images
- Phone numbers
- Email addresses
- Home addresses
- Usernames
- Mentions of my name

For every website where my personal information appears, provide:
1. Website name
2. What information is exposed
3. Direct profile/page URL
4. Official opt-out or removal request link
5. Difficulty level (Easy/Medium/Hard)
6. Whether manual verification is required

Present the results in a clean table and prioritize websites that expose sensitive personal information.

*****************************************************

Prompt 2 – Generate Removal Requests

For every website you found, write the exact removal request or opt-out message I should submit.

If a site has a specific opt-out process, explain the exact steps required.

If different websites require different information, tailor the request accordingly.

Keep every request professional, concise, and ready to copy and paste.

*****************************************************

Prompt 3 – Agent Mode (Most Important)

Open each official opt-out page, complete the removal process wherever possible, and submit the removal request on my behalf.

If any step requires my confirmation, identity verification, CAPTCHA, email verification, or additional information, pause and ask for my approval before proceeding.

Keep track of:
- Successfully submitted requests
- Requests requiring my action
- Websites that couldn't be processed
- Any follow-up actions needed

Provide a final summary after all websites have been processed.

*****************************************************

Prompt 4 – Weekly Monitoring Task

Create a recurring weekly task to search for my personal information across the same websites and any new data broker or people-search websites.

If any previously removed information reappears or a removal request was ignored, notify me and prepare the appropriate follow-up removal request.

Provide a summary of any changes after each weekly scan.
